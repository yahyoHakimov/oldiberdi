# OldiBerdi - Peer-to-Peer Loan and Debt Management

## Project Description

OldiBerdi is a peer-to-peer loan and debt management application designed to solve common issues that arise when borrowing and lending money among friends, family, and groups. It simplifies loan agreements, tracks repayment deadlines, and automates reminders, ensuring a smooth process for both borrowers and lenders.

## Features

- **Loan Requests:** Borrowers can send loan requests with a specified repayment date.
- **Group Lending:** Users can create or join groups (e.g., friends, classmates) for collective lending.
- **Notifications:** Automatic reminders sent to borrowers on repayment due dates.
- **Dispute Resolution:** Legal agreement (offerta) that can escalate to legal action if a loan is not repaid.
- **Financial Tracking:** Users can track their loans, debts, and expenses.
  
## Business Model

- **Transaction Fee:** A small percentage is charged on each loan transaction.
- **Subscription Plans:** Premium features available through a subscription fee.
